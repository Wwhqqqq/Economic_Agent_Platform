# 会员专享知识库 — 知识来源说明

> 本目录为 **会员专享 RAG 知识库**（`visibility=member`）的运维灌库语料，非用户个人上传文档。
> 最后更新：2026-08-09

## 一、内容性质与版权说明

本知识库内容均为 **基于公开权威资料编写的结构化摘要与实务指南**，用于财务审计、报表分析、准则咨询等场景的 RAG 检索增强。

| 类型 | 说明 |
|------|------|
| **政府公开文件** | 财政部、中注协等发布的准则、通知、暂行规定 — 可公开引用，本库为摘要非全文转载 |
| **法律法规** | 增值税法、企业所得税法等 — 概要性说明，以官方法规文本为准 |
| **国际准则参考** | IFRS/IAS 趋同对照 — 参考 EU-endorsed 公开索引，**未收录 IFRS Foundation 版权全文** |
| **教育框架** | COSO 内控、财务分析方法论 — 公开框架的概念性摘要 |
| **不包含** | 整本教材、付费数据库、未授权论文全文、盗版 PDF |

如需引用准则原文，请访问下列官方来源获取最新版本。

## 四、灌库与更新

```bash
cd backend

# 首次灌库 / 增量更新（跳过未变更文档）
python -m scripts.seed_member_knowledge

# 强制全量重建索引
python -m scripts.seed_member_knowledge --force

# 单篇更新
python -m scripts.seed_member_knowledge --doc member-cas-framework
```

灌库后：
- MySQL `knowledge_documents`：`visibility=member`, `user_id=NULL`
- Chroma / Neo4j：`user_id=0`, `visibility=member`
- 仅 **会员用户** RAG 可检索（见 `tenant_filter.py`）

## 五、后续扩展建议

1. **准则原文 PDF**：从财政部官网下载后放入 `data/member_knowledge/pdfs/`，扩展脚本支持 PDF ingest
2. **准则解释与应用案例**：CASC 实施问答可按专题追加
3. **行业指引**：证监会会计监管报告、交易所指引
4. **开放论文**：SSRN/arXiv 上 CC 许可的会计研究（需逐篇确认许可）
5. **定期更新**：准则修订后更新对应摘要并 `--force` 重建
