# 中国主要税种基础（增值税与企业所得税）

> **知识来源**：《中华人民共和国增值税法》（2024通过，2026施行过渡）、《企业所得税法》及实施条例；国家税务总局政策法规库。
> **说明**：税法以最新官方法规为准，本文件为 RAG 检索用的结构化概要。

## 一、增值税

### 1.1 纳税人

- **一般纳税人**：年应税销售额超过规定标准（通常 500 万元），可抵扣进项
- **小规模纳税人**：简易征收，征收率 3%（阶段性优惠可能调整）

### 1.2 税率与征收率（一般规定）

| 类型 | 税率/征收率 | 范围 |
|------|-------------|------|
| 标准税率 | 13% | 货物、加工修理修配、有形动产租赁 |
| 低税率 | 9% | 交通运输、邮政、基础电信、建筑、不动产租赁、农产品等 |
| 低税率 | 6% | 现代服务、生活服务、金融服务、无形资产（除土地使用权） |
| 零税率 | 0% | 出口货物、跨境应税行为（可退税） |
| 简易征收 | 3% / 5% | 小规模或特定一般纳税人项目 |

### 1.3 应纳税额计算

**一般纳税人**：
```
应纳税额 = 当期销项税额 - 当期进项税额
```

**小规模纳税人**：
```
应纳税额 = 销售额 × 征收率（不含税销售额）
```

### 1.4 进项抵扣要点

- 取得合法扣税凭证
- 用于应税项目
- 不得抵扣：简易计税、免税、集体福利、个人消费、非正常损失等

### 1.5 发票管理

- 增值税专用发票 → 抵扣进项
- 增值税普通发票 → 一般不可抵扣（特定行业例外）
- 全电发票推广中

### 1.6 会计处理（简要）

```
借：原材料/费用等
    应交税费——应交增值税（进项税额）
    贷：应付账款

借：应收账款
    贷：主营业务收入
        应交税费——应交增值税（销项税额）
```

## 二、企业所得税

### 2.1 纳税人

居民企业（依法在中国境内成立，或实际管理机构在中国境内）→ 全球所得纳税。
非居民企业 → 仅就境内来源所得纳税。

### 2.2 税率

| 类型 | 税率 |
|------|------|
| 一般企业 | 25% |
| 小型微利企业 | 优惠税率（如 20% 减按 5%/10% 实际，政策动态调整） |
| 高新技术企业 | 15% |
| 非居民企业（源泉） | 10%（可税收协定减免） |

### 2.3 应纳税所得额

```
应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 允许弥补的以前年度亏损
```

### 2.4 税前扣除原则

- 真实、合法、相关
- 区分资本性支出（不得一次性扣除）与收益性支出
- 限额扣除：职工福利费（14%）、工会经费（2%）、职工教育经费（8%）、广告业务宣传费（15%/30%）、公益性捐赠（12%）等

### 2.5 资产折旧与摊销

- 直线法为主，加速折旧经备案可用
- 最低折旧年限：房屋建筑物 20 年、机器设备 10 年、电子设备 3 年等

### 2.6 纳税调整

| 类型 | 示例 |
|------|------|
| 调增 | 业务招待费超限、税收滞纳金、未经核定的准备金 |
| 调减 | 国债利息、符合条件的股息红利、研发费用加计扣除 |

### 2.7 研发费用加计扣除

- 制造业等行业：100% 加计扣除（政策期动态）
- 形成无形资产的，按 200% 摊销

### 2.8 递延所得税（CAS 18 勾稽）

- 暂时性差异 → 递延所得税资产/负债
- 可抵扣亏损 → 递延所得税资产（以很可能获得应纳税所得为限）

## 三、其他常见税种（概要）

| 税种 | 要点 |
|------|------|
| 消费税 | 特定消费品（烟、酒、油、车、奢侈品等），价内税 |
| 印花税 | 合同、产权转移书据、营业账簿等 |
| 房产税 | 从价 1.2%（或 12% 从租） |
| 土地使用税 | 按面积定额 |
| 个人所得税 | 综合所得 3%-45% 七级超额累进 |
| 城建税及附加 | 以增值税、消费税为计税依据 |

## 四、税务与会计差异

- **永久性差异**：不确认递延（如罚款、部分免税）
- **暂时性差异**：确认递延所得税（折旧年限、减值、预提费用等）
