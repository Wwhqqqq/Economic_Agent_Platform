# 合并财务报表（CAS 33 / CAS 20）

> **知识来源**：财政部 CAS 33、CAS 20；与 IFRS 10/IFRS 3 趋同。

## 一、合并范围

### 1.1 控制的三要素（CAS 33）

1. **拥有权力**：主导被投资方相关活动的现时能力
2. **享有可变回报**：因参与被投资方而面临可变回报的风险或享有权利
3. **有能力运用权力影响回报**：对可变回报的影响程度

### 1.2 控制 vs 重大影响 vs 共同控制

| 关系 | 持股比例参考 | 会计处理 |
|------|-------------|----------|
| 控制 | 通常 >50% 或实质控制 | 合并报表 |
| 共同控制 | 合同安排 | 合营企业：权益法（CAS 2） |
| 重大影响 | 通常 20%-50% | 联营企业：权益法 |
| 无重大影响 | <20% | 金融工具准则 |

## 二、企业合并（CAS 20）

### 2.1 同一控制下合并

- 按被合并方**账面价值**计量
- 差额调整资本公积，不足冲减留存收益
- 比较报表需追溯调整

### 2.2 非同一控制下合并

- 按**购买日公允价值**计量可辨认资产、负债
- 商誉 = 合并成本 - 享有被购买方可辨认净资产公允价值份额
- 负商誉（廉价购买）计入当期损益

### 2.3 合并成本构成

- 支付现金、转让非现金资产、承担负债、发行权益性证券的公允价值
- 直接相关费用 → 计入当期损益（非合并成本）

## 三、合并程序

### 3.1 统一会计政策与期间

母子公司会计政策不一致 → 按母公司政策调整。
会计期间不一致 → 按母公司期间调整或采用最近期间数据。

### 3.2 抵消分录

1. **长期股权投资与子公司所有者权益**
2. **投资收益与子公司利润分配**
3. **内部交易**（商品、固定资产、无形资产、债权债务）
4. **内部未实现利润**（顺流/逆流/平流交易）

### 3.3 少数股东权益

合并资产负债表中单独列示：
- 少数股东享有的子公司净资产份额
- 少数股东损益在合并利润表单独列示

## 四、特殊交易

### 4.1 分步实现非同一控制合并

- 原持有股权按购买日公允价值重新计量，差额计入投资收益
- 原 OCI 重分类进损益（指定 FVOCI 的权益工具除外）

### 4.2 处置子公司（丧失控制）

- 剩余股权按丧失控制权日公允价值重新计量
- 原商誉相关部分终止确认
- 差额计入投资收益

### 4.3 因子公司少数股东增资导致股权稀释

- 不丧失控制 → 调整资本公积，不确认损益

## 五、合并现金流量表

- 抵消内部现金收支
- 子公司自购买日起纳入合并
- 处置子公司自丧失控制日起不再纳入

## 六、披露（CAS 41 补充）

- 子公司、合营、联营清单及持股比例
- 纳入/未纳入合并范围的结构化主体
- 丧失控制权的判断及影响

## 七、审计关注点

1. 控制判断（结构化主体、委托/受托经营）
2. 商誉减值测试（CAS 8 + 商誉分摊至资产组）
3. 内部交易抵消完整性
4. 购买日公允价值评估（评估师工作）
5. 同一控制合并的追溯调整
6. 少数股东权益计算
