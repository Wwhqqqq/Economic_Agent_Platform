# 收入确认与存货会计（CAS14 / CAS1）

> **知识来源**：财政部《企业会计准则第14号——收入》（2017修订，2018年1月1日施行）；《企业会计准则第1号——存货》；IFRS 15 趋同参考。
> **核心变化**：CAS 14（2017）采用五步法模型，与 IFRS 15 趋同，取代旧准则的"风险报酬转移"模型。

## 一、收入准则（CAS 14）五步法

### 步骤1：识别与客户订立的合同

合同需同时满足：
- 合同各方已批准并承诺履行
- 明确了所转让商品或提供劳务的内容
- 有明确的支付条款
- 具有商业实质
- 对价很可能收回

### 步骤2：识别合同中的单项履约义务

- 可明确区分的商品/服务 → 单项履约义务
- 一系列实质相同且转让模式相同的 → 可合并为一项
- 判断标准：客户能否从该商品中单独获益 + 是否可单独区分

### 步骤3：确定交易价格

交易价格 = 预期有权收取的对价（不含代第三方收取的款项）。

需考虑：
- **可变对价**：期望值法或最可能发生金额法，且需满足"极可能不会发生重大转回"
- **重大融资成分**：超过一年以上的对价时间差
- **非现金对价**：公允价值计量
- **应付客户对价**：冲减交易价格

### 步骤4：将交易价格分摊至各履约义务

按各单项履约义务单独售价的相对比例分摊。单独售价无法直接观察时，采用调整市场价、成本加成或余值法。

### 步骤5：履行履约义务时确认收入

| 类型 | 确认时点 | 典型场景 |
|------|----------|----------|
| 在某一时点履行 | 控制权转移时 | 商品销售、交付软件许可 |
| 在某一时段内履行 | 进度法（投入/产出） | 工程施工、长期服务合同 |

**控制权转移判断**（时点型）：
- 现时收款权利
- 法定所有权转移
- 实物转移
- 主要风险和报酬转移
- 客户接受

### 特殊交易

**合同成本**：增量成本（如销售佣金）和满足条件的合同履约成本可资本化，摊销计入当期损益。

**主要责任人 vs 代理人**：控制商品再转让的为主要责任人，按总额确认收入；否则按净额（佣金）确认。

**质保**：保证类质保按 CAS 13 或有事项处理；服务类质保作为单项履约义务。

## 二、存货准则（CAS 1）

### 2.1 存货范围

持有以备出售的产成品或商品、处在生产过程中的在产品、在生产或提供劳务过程中耗用的材料和物料等。

### 2.2 初始计量

| 来源 | 计量 |
|------|------|
| 外购 | 采购成本 = 购买价款 + 相关税费 + 运输装卸费 + 其他可归属成本 |
| 自制 | 加工成本 = 直接材料 + 直接人工 + 制造费用 |
| 投资者投入 | 投资合同或协议约定的价值（不公允的除外） |
| 非货币性交换/债务重组 | 按 CAS 7 / CAS 12 处理 |

### 2.3 发出计价方法

加权平均法、个别计价法、先进先出法。**禁止后进先出法（LIFO）**。

### 2.4 期末计量——成本与可变现净值孰低

**可变现净值** = 估计售价 - 至完工估计成本 - 估计销售费用及相关税费

| 存货类型 | 可变现净值确定 |
|----------|----------------|
| 产成品/商品 | 估计售价 - 估计销售费用及税费 |
| 需加工材料 | 用其生产的产成品估计售价 - 至完工成本 - 销售费用及税费 |

计提存货跌价准备：
```
借：资产减值损失
    贷：存货跌价准备
```

以前减记因素消失时，在原已计提范围内转回。

### 2.5 披露要点

- 各类存货期初期末账面价值
- 存货可变现净值的确定依据
- 存货跌价准备计提/转回/核销

## 三、收入与存货的勾稽（审计关注点）

1. 已发货未确认收入 → 检查控制权转移时点
2. 收入确认但存货未结转 → 成本配比
3. 毛利率异常波动 → 收入确认政策或成本计价变更
4. 期后退货 → 资产负债表日后事项 / 可变对价
5. 建造合同进度 → 投入法与产出法一致性
