# 中国注册会计师审计准则框架

> **知识来源**：中国注册会计师协会已发布审计准则；财政部财会〔2022〕36号（2023年7月1日施行修订）；与 ISA 持续趋同。

## 一、准则体系结构

中国注册会计师审计准则包括：

| 类别 | 编号范围 | 内容 |
|------|----------|------|
| 总则 | 1101-1123 | 目标、职业道德、质量控制 |
| 风险识别与评估 | 1211 | 重大错报风险识别和评估（2023修订） |
| 风险应对 | 1231 | 针对评估风险的程序 |
| 进一步审计程序 | 1301-1332 | 审计证据、抽样、分析程序、函证等 |
| 完成与报告 | 1501-1521 | 期后事项、持续经营、审计报告 |
| 特殊行业/领域 | 1601-1633 | 集团审计、内部控制、其他特殊目的 |
| 审阅与其他 | 2101-2304 | 审阅、执行商定程序、其他鉴证 |

## 二、风险导向审计模型

### 2.1 审计风险公式

```
审计风险 = 重大错报风险 × 检查风险
```

- **重大错报风险**：固有风险 × 控制风险（2018后更强调"认定层次"评估）
- **检查风险**：可接受水平，通过审计程序控制

### 2.2 审计流程

1. **接受业务** → 客户诚信、胜任能力、独立性
2. **计划审计** → 总体策略、具体计划
3. **了解被审计单位及环境** → 内部控制、重大错报风险
4. **识别和评估重大错报风险**（1211号）
5. **设计和实施进一步审计程序**（1231号）
6. **评价审计证据** → 充分适当
7. **形成审计意见** → 无保留/保留/否定/无法表示

## 三、1211号准则要点（2023修订）

### 3.1 风险评估程序

- 询问、分析程序、观察和检查
- 了解内部控制（非必须测试，但需了解）
- 识别特别风险：舞弊、重大估计、复杂交易

### 3.2 固有风险因素

- 复杂性
- 主观性
- 变化程度
- 不确定性
- 其他（如关联交易、超出正常经营过程的重大交易）

### 3.3 会计估计（1321号配套）

- 识别管理层偏向
- 评价估计不确定性
- 点估计 vs 区间估计

## 四、审计证据（1301号）

### 4.1 充分适当

- **充分性**：数量
- **适当性**：质量（相关、可靠）

### 4.2 证据来源

| 来源 | 可靠性 |
|------|--------|
| 外部独立来源 | 高 |
| 外部非独立 | 中 |
| 内部（控制有效） | 中 |
| 内部（控制无效） | 低 |

### 4.3 函证（1151号）

- 银行存款、借款、应收款项等
- 未回函替代程序
- 电子函证平台

## 五、审计报告（1501号）

### 5.1 意见类型

| 类型 | 条件 |
|------|------|
| 无保留 | 在所有重大方面公允反映 |
| 保留 | 错报重大但不广泛 / 无法获取充分证据但不广泛 |
| 否定 | 错报重大且广泛 |
| 无法表示 | 无法获取充分证据且可能广泛 |

### 5.2 关键审计事项（KAM）

上市实体审计报告中沟通 KAM：审计中认为最重要的事项。

### 5.3 强调事项段

不影响意见，但需使用者关注（如持续经营重大不确定性、期后事项）。

## 六、职业道德与独立性

- 中国注册会计师职业道德守则
- 独立性：经济利益、密切关系、自我评价、过度推介、胁迫
- 轮换：项目合伙人、签字注册会计师定期轮换（公众利益实体）

## 七、2023年修订影响

财会〔2022〕36号修订 1211、1321 及 23 项准则一致性条款：
- 强化风险评估的系统性
- 会计估计审计要求更细
- 与 ISA 2018 修订保持趋同
