# 所得税与递延所得税（CAS 18 / IAS 12）

> **知识来源**：财政部 CAS 18；IAS 12 趋同；《企业所得税法》。

## 一、会计与税法差异

### 1.1 永久性差异

- 永远不影响未来 taxable income
- 示例：税收滞纳金、部分罚款、免税国债利息（会计确认但税法免税）
- **不确认递延所得税**

### 1.2 暂时性差异

- 资产/负债账面价值与计税基础不同
- 未来会转回
- **确认递延所得税**

```
暂时性差异 = 账面价值 - 计税基础（资产）
            或 计税基础 - 账面价值（负债）
```

## 二、递延所得税资产与负债

### 2.1 确认原则

| 差异类型 | 影响 | 确认 |
|----------|------|------|
| 应纳税暂时性差异 | 未来多交税 | 递延所得税负债 |
| 可抵扣暂时性差异 | 未来少交税 | 递延所得税资产 |
| 可抵扣亏损 | 未来少交税 | 递延所得税资产 |

### 2.2 计量

- 按预期收回/清偿期间的适用税率
- 直接计入所有者权益的 → 不通过损益（如 FVOCI 公允价值变动）

### 2.3 递延所得税资产确认限制

```
确认上限 = min(可抵扣暂时性差异+可抵扣亏损, 很可能获得的 taxable income)
```

## 三、常见暂时性差异来源

| 项目 | 典型差异 |
|------|----------|
| 固定资产 | 折旧年限/方法不同 |
| 无形资产 | 摊销、研发资本化 |
| 资产减值 | 会计计提，税法未经核定不得扣除 |
| 预计负债 | 会计确认，实际发生才税前扣除 |
| 预收账款 | 税法可能更早确认收入 |
| 公允价值变动 | 交易性金融资产等 |
| 股份支付 | 等待期费用 vs 行权扣除 |

## 四、所得税费用

```
所得税费用 = 当期所得税 + 递延所得税
当期所得税 = 应纳税所得额 × 适用税率
```

### 4.1 利润表列示

- 所得税费用
- 附注披露：当期所得税、递延所得税、有效税率调节表

### 4.2 有效税率调节

```
法定税率 25%
+ 不可抵扣费用影响
+ 免税收入影响
+ 税率变动影响
+ 未确认递延所得税资产
= 实际有效税率
```

## 五、特殊事项

### 5.1 商誉

- 初始确认商誉 → 不确认递延所得税负债（例外）
- 商誉减值 → 通常不产生递延

### 5.2 企业合并

- 购买日资产/负债按公允价值 → 计税基础可能不同 → 递延

### 5.3 直接计入权益

- 其他综合收益相关的递延 → 计入 OCI

## 六、列报

- 递延所得税资产/负债：非流动（除非 12 个月内转回）
- 净额列示：同一税务机关、有法定抵销权

## 七、审计关注点

1. 递延所得税资产确认是否谨慎（可抵扣亏损、减值）
2. 税率预期是否合理
3. 永久性 vs 暂时性差异分类
4. 有效税率调节表勾稽
5. 与税务申报表差异
