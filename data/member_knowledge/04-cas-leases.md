# 租赁会计（CAS 21 / IFRS 16）

> **知识来源**：财政部《企业会计准则第21号——租赁》（2018修订，2019年1月1日施行）；与 IFRS 16 趋同。
> **核心变化**：承租人不再区分经营租赁与融资租赁，几乎所有租赁均确认使用权资产和租赁负债（短期租赁和低价值资产租赁除外）。

## 一、适用范围

适用于几乎所有租赁安排，但以下除外：
- 租赁合同采用 CAS 14 处理的（如已作为销售的一部分）
- 勘探或使用矿产、石油、天然气等
- 生物资产（CAS 5）
- 服务合同（无已识别资产）

## 二、承租人会计处理

### 2.1 识别租赁

合同让渡了**已识别资产**在**一定期间**内的**控制权** → 租赁。

- **已识别资产**：合同明确指定或隐性指定
- **控制权**：有权获得几乎全部经济利益 + 有权主导使用

### 2.2 豁免

| 豁免类型 | 条件 | 处理 |
|----------|------|------|
| 短期租赁 | 租赁期 ≤ 12个月 | 直线法计入损益 |
| 低价值资产 | 全新时价值较低（通常 ≤ 5000美元/人民币等值） | 直线法计入损益 |

### 2.3 初始计量

**使用权资产** = 租赁负债初始计量 + 预付租金 + 初始直接费用 + 复原成本估计 - 租赁激励

**租赁负债** = 尚未支付的租赁付款额按租赁内含利率折现（无法确定时用增量借款利率）

### 2.4 后续计量

**使用权资产**：
- 成本模式：原值 - 累计折旧 - 减值
- 折旧年限：租赁期与剩余使用寿命孰短

**租赁负债**：
- 按实际利率法摊销
- 重新计量：租赁变更、指数/比率变动、剩余价值担保等

### 2.5 分录示例

初始确认：
```
借：使用权资产
    贷：租赁负债
        银行存款（预付/直接费用等）
```

后续：
```
借：管理费用/制造费用（折旧）
    贷：使用权资产累计折旧

借：财务费用（利息）
    贷：租赁负债
```

## 三、出租人会计处理

### 3.1 分类

| 类型 | 判断 | 处理 |
|------|------|------|
| 融资租赁 | 转移几乎全部风险和报酬 | 确认应收融资租赁款，终止确认资产 |
| 经营租赁 | 其他 | 保留资产，直线法确认租金收入 |

### 3.2 融资租赁关键指标

- 租赁期占资产使用寿命大部分（≥75%）
- 最低租赁付款额现值≈公允价值（≥90%）
- 资产专属性
- 承租人续租/购买选择权

## 四、租赁变更

- **单独租赁**：增加使用范围或延长期限且有对价 → 作为新租赁
- **非单独租赁**：重新计量租赁负债，调整使用权资产

## 五、列报与披露

### 承租人

- 资产负债表：使用权资产（非流动/流动）、租赁负债（流动/非流动）
- 利润表：折旧费用、利息费用
- 披露：租赁活动性质、未来现金流出、可变租赁付款、续租/终止选择权

### 出租人

- 融资租赁：应收融资租赁款、未实现融资收益
- 经营租赁：披露不可撤销经营租赁的未来最低租赁收款额

## 六、CAS 21 与 IFRS 16 主要差异

- 总体趋同，细节差异在 COVID-19 相关实务豁免、低价值阈值指引等
- 我国准则应用指南对特定行业（如零售、航空）有补充案例

## 七、审计关注点

1. 租赁识别是否完整（尤其是嵌入式租赁、转租）
2. 折现率选择是否合理
3. 租赁期是否包含续租/终止选择权
4. 短期/低价值豁免是否滥用
5. 租赁负债与使用权资产勾稽
6. 租赁变更处理是否正确
