# 财务报表分析与关键财务比率

> **知识来源**：CAS 30 财务报表列报；公开财务分析框架（CFA/教材通用方法论）；本文件为结构化分析指南。

## 一、分析框架

### 1.1 分析目的

- 评估盈利能力、偿债能力、营运能力、成长能力
- 识别财务异常与舞弊风险信号
- 支持信贷决策、投资决策、审计风险评估

### 1.2 分析层次

1. **战略与行业** → 波特五力、行业周期
2. **会计质量** → 政策选择、估计、盈余管理
3. **财务比率** → 横向/纵向比较
4. **现金流** → 利润质量
5. **前景预测** → 敏感性、情景分析

## 二、盈利能力比率

| 比率 | 公式 | 解读 |
|------|------|------|
| 毛利率 | (营业收入-营业成本)/营业收入 | 产品竞争力、定价能力 |
| 营业利润率 | 营业利润/营业收入 | 经营效率 |
| 净利率 | 净利润/营业收入 | 综合盈利 |
| ROA | 净利润/平均总资产 | 资产运用效率 |
| ROE | 净利润/平均净资产 | 股东回报（杜邦核心） |
| ROIC | NOPAT/投入资本 | 剔除财务杠杆影响 |

### 杜邦分析

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利润/收入) × (收入/总资产) × (总资产/净资产)
```

## 三、偿债能力比率

### 3.1 短期偿债

| 比率 | 公式 | 参考 |
|------|------|------|
| 流动比率 | 流动资产/流动负债 | 一般 1.5-2.0 |
| 速动比率 | (流动资产-存货)/流动负债 | 一般 ≥1.0 |
| 现金比率 | 货币资金/流动负债 | 最保守 |
| 营运资本 | 流动资产-流动负债 | 绝对数 |

### 3.2 长期偿债

| 比率 | 公式 |
|------|------|
| 资产负债率 | 总负债/总资产 |
| 产权比率 | 总负债/净资产 |
| 利息保障倍数 | EBIT/利息费用 |
| 债务/EBITDA | 净债务/EBITDA |

## 四、营运能力比率

| 比率 | 公式 | 含义 |
|------|------|------|
| 应收账款周转率 | 收入/平均应收账款 | 收款效率 |
| 应收账款周转天数 | 365/周转率 | 平均账期 |
| 存货周转率 | 成本/平均存货 | 存货管理 |
| 存货周转天数 | 365/周转率 | 平均持有期 |
| 总资产周转率 | 收入/平均总资产 | 整体资产效率 |
| 固定资产周转率 | 收入/平均固定资产 | 产能利用 |

## 五、成长能力

| 指标 | 计算 |
|------|------|
| 收入增长率 | (本期-上期)/上期 |
| 净利润增长率 | 同上 |
| 可持续增长率 | ROE × (1-股利支付率) |
| 资本支出/折旧 | 扩张 vs 维护 |

## 六、现金流分析

### 6.1 三大活动

- **经营活动**：核心造血能力
- **投资活动**：扩张/收缩
- **筹资活动**：融资结构变化

### 6.2 关键指标

| 指标 | 公式/含义 |
|------|-----------|
| 经营现金流/净利润 | >1 表示利润有现金支撑 |
| 自由现金流 FCF | 经营现金流 - 资本支出 |
| 现金转换周期 | 存货天数 + 应收天数 - 应付天数 |
| 获现率 | 销售商品收到现金/营业收入 |

### 6.3 红旗信号

- 利润增长但经营现金流持续为负
- 应收/存货增速远超收入增速
- 频繁依赖筹资活动维持经营
- 大额非经常性损益粉饰利润

## 七、财务舞弊识别（Benford/异常检测）

- 收入确认时点激进
- 毛利率与同行严重偏离
- 关联交易占比异常
- 审计师频繁变更
- 管理层更换伴随业绩变脸

## 八、行业差异提示

| 行业 | 关注重点 |
|------|----------|
| 制造业 | 存货周转、固定资产利用率 |
| 零售 | 同店增长、现金转换周期 |
| 金融 | 资本充足率、不良率、拨备覆盖率 |
| 房地产 | 预收账款、存货（开发成本）、三道红线 |
| 科技 | 研发费用资本化、收入确认（SaaS） |
