# 长期股权投资（CAS 2）

> **知识来源**：财政部 CAS 2（2014修订）；IAS 28、IFRS 11 趋同。

## 一、范围与分类

### 1.1 投资方对被投资单位的影响程度

| 类型 | 判断 | 后续计量 |
|------|------|----------|
| 控制 | 有权决定被投资方相关活动 | 成本法（个别报表）/ 合并（合并报表） |
| 共同控制 | 按合同约定共同控制 | 合营：权益法 |
| 重大影响 | 参与财务经营决策 | 联营：权益法 |
| 无重大影响 | 通常 <20% | 金融工具准则（CAS 22） |

### 1.2 重大影响判断因素

- 持股比例 20%-50% 一般假定有重大影响
- 派出董事、参与政策制定、重大交易、互派管理人员、提供关键技术

## 二、初始计量

| 取得方式 | 计量 |
|----------|------|
| 企业合并（同一控制） | 被合并方账面价值份额 |
| 企业合并（非同一控制） | 合并成本公允价值 |
| 其他方式 | 实际支付对价 + 直接费用 |

### 2.1 发行权益性证券

- 公允价值作为初始成本
- 发行费用冲减资本公积

## 三、后续计量——权益法

### 3.1 基本原则

```
长期股权投资账面价值 = 初始成本 ± 损益调整 ± 其他综合收益调整 ± 其他权益变动
```

### 3.2 投资收益确认

```
投资收益 = 被投资方当期净利润 × 持股比例
         ± 顺流/逆流未实现内部交易调整
         ± 会计政策/期间不一致调整
```

### 3.3 其他综合收益

- 被投资方 OCI 变动 → 投资方按份额调整长期股权投资 + 其他综合收益

### 3.4 宣告股利

```
借：应收股利
    贷：长期股权投资——损益调整
```

### 3.5 超额亏损

- 减记至零为限
- 未确认份额在备查簿登记
- 被投资方以后盈利 → 按未确认顺序恢复

## 四、成本法（对子公司个别报表）

- 除追加/处置投资、减值外，账面价值不变
- 被投资方宣告股利 → 确认投资收益

## 五、转换与处置

### 5.1 因追加投资等导致计量方法变更

- 公允价值计量 → 权益法：原股权公允价值作为新初始成本
- 权益法 → 成本法（丧失共同/重大影响）：剩余按成本法，终止权益法

### 5.2 处置

```
处置损益 = 处置价款 - 账面价值 ± 其他综合收益结转 ± 资本公积结转
```

## 六、减值（CAS 8）

- 成本法/权益法均适用 CAS 8
- 可收回金额低于账面 → 计提减值，**不可转回**

## 七、披露

- 联营/合营清单、持股比例
- 会计政策差异及调整
- 未确认超额亏损
- 与合营/联营交易的未实现利润
