# 四表一注结构与勾稽关系

> **知识来源**：CAS 30 财务报表列报、CAS 31 现金流量表、CAS 33 合并财务报表。

## 一、四表一注

| 报表 | 核心内容 |
|------|----------|
| 资产负债表 | 财务状况（时点） |
| 利润表 | 经营成果（期间） |
| 现金流量表 | 现金及等价物流入流出（期间） |
| 所有者权益变动表 | 权益各组成部分变动 |
| 附注 | 会计政策、重要项目明细、或有事项、关联方等 |

## 二、资产负债表结构

### 2.1 资产（流动性排列）

**流动资产**：货币资金、交易性金融资产、衍生金融资产、应收票据、应收账款、应收款项融资、预付款项、其他应收款、存货、合同资产、持有待售资产、一年内到期的非流动资产。

**非流动资产**：债权投资、长期股权投资、其他权益工具投资、投资性房地产、固定资产、在建工程、使用权资产、无形资产、开发支出、商誉、长期待摊费用、递延所得税资产。

### 2.2 负债

**流动负债**：短期借款、交易性金融负债、应付票据、应付账款、合同负债、应付职工薪酬、应交税费、其他应付款、一年内到期的非流动负债。

**非流动负债**：长期借款、应付债券、租赁负债、长期应付款、预计负债、递延所得税负债。

### 2.3 所有者权益

实收资本、资本公积、其他综合收益、盈余公积、未分配利润、少数股东权益（合并）。

### 2.4 恒等式

```
资产 = 负债 + 所有者权益
```

## 三、利润表结构（多步式）

```
营业收入
减：营业成本、税金及附加、销售费用、管理费用、研发费用、财务费用
加：其他收益、投资收益、公允价值变动、信用减值、资产减值
营业利润
加：营业外收入
减：营业外支出
利润总额
减：所得税费用
净利润
```

### 其他综合收益（OCI）

- 不能重分类进损益：重新计量设定受益计划、权益工具 FVOCI 公允价值变动
- 将重分类进损益：债权投资 FVOCI、外币折算差额等

## 四、现金流量表（间接法补充资料）

### 4.1 三类活动

| 活动 | 典型项目 |
|------|----------|
| 经营活动 | 销售商品收到现金、购买商品支付现金、支付职工薪酬 |
| 投资活动 | 购建固定资产、取得/处置子公司、投资支付/收回 |
| 筹资活动 | 借款、还款、发行股票、分红 |

### 4.2 间接法调节

```
净利润
+ 资产减值准备、折旧、摊销、财务费用、投资损失、递延所得税等
± 经营性应收应付变动
= 经营活动现金流量净额
```

## 五、核心勾稽关系

### 5.1 表间勾稽

1. **利润表净利润** → 所有者权益变动表"未分配利润"变动
2. **折旧摊销** → 利润表费用 ↔ 现金流量表间接法加回 ↔ 资产账面价值减少
3. **期末货币资金** → 资产负债表 ↔ 现金流量表"现金及等价物净增加额"调节
4. **合并利润表"归属于母公司净利润"** + 少数股东损益 = 净利润
5. **长期股权投资** ↔ 联营/合营权益法投资收益

### 5.2 与附注勾稽

- 应收账款账面余额 ↔ 附注坏账准备明细
- 固定资产原值/累计折旧 ↔ 附注增减变动表
- 收入分部 ↔ 附注分部报告
- 关联方余额 ↔ 附注关联方交易

## 六、常见编制错误

- 现金流量表分类错误（如借款利息归入筹资 vs 经营）
- 未实现内部交易未抵消
- 外币报表折算差额遗漏
- 合同资产/负债（CAS 14）列报位置错误
