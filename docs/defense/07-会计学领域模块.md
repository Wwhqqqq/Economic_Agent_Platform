# 07 — 会计学领域模块

本模块是项目的**垂直领域核心**，将通用 Agent 能力落地到会计学 / 财务分析场景。

---

## 1. 领域设计原则

| 原则 | 说明 |
|------|------|
| **确定性计算** | 财务数字由 Python 工具精确计算，不依赖 LLM 算术 |
| **LLM 做解读** | LLM 负责理解数据、生成报告、组织论证 |
| **工具链编排** | 审计 SOP 固化为 Pipeline，保证分析链条完整 |
| **多角度验证** | Multi-Agent 辩论模拟真实评审流程 |
| **中英文兼容** | 工具输入支持中英文字段名 |

---

## 2. 五大会计分析工具

所有工具位于 `backend/app/tools/accounting/`，输入均为 **JSON 字符串**。

### 2.1 balance_sheet_analyzer — 资产负债表分析

**文件：** `balance_sheet.py`

| action | 功能 | 输出 |
|--------|------|------|
| `verify` | 验证会计恒等式 A = L + E | ✅/❌ 是否平衡，差额 |
| `ratio` | 流动比率、资产负债率 | 数值 + 解读 |
| `analyze` | 资产/负债结构分析 | 占比、结构评价 |

**关键公式：**
```
流动比率 = 流动资产 / 流动负债
资产负债率 = 总负债 / 总资产 × 100%
```

### 2.2 income_statement_analyzer — 利润表分析

**文件：** `income_statement.py`

| 分析项 | 说明 |
|--------|------|
| 营收与成本 | 总收入、COGS、毛利润 |
| 利润率 | 毛利率、营业利润率、净利率 |
| 同比趋势 | 与 previous_period 对比，计算增长率 |
| 费用结构 | 营业费用占比 |

### 2.3 cash_flow_analyzer — 现金流量表分析

**文件：** `cash_flow.py`

| 分析项 | 说明 |
|--------|------|
| 三大活动 | 经营/投资/融资现金流 |
| 自由现金流 | 经营现金流 - 资本支出 |
| 盈利质量 | 净利润 vs 经营现金流对比 |
| 红旗信号 | 利润增但现金流减 → 盈利质量存疑 |

### 2.4 financial_ratio_calculator — 综合财务比率

**文件：** `financial_ratio.py`

四大类比率，带分级评价（emoji 标记）：

| 类别 | 指标 | 优秀基准 |
|------|------|----------|
| **盈利能力** profitability | ROE, ROA, NPM, GPM | ROE ≥ 20% 🏆 |
| **偿债能力** solvency | 资产负债率, 流动比率, 速动比率 | 流动比率 ≥ 2.0 🏆 |
| **营运能力** efficiency | 总资产周转率, 存货周转率 | — |
| **成长能力** growth | 营收增长率, 净利润增长率 | — |

**分级逻辑示例（ROE）：**
```
≥ 20% → 🏆  优秀
≥ 15% → ✅  良好
≥ 10% → ⚠️  一般
< 10% → 🔴  较差
```

### 2.5 dupont_analysis — 杜邦分析

**文件：** `dupont_analysis.py`

**核心公式：**
```
ROE = 净利率 × 总资产周转率 × 权益乘数

其中：
  净利率 = 净利润 / 营收
  总资产周转率 = 营收 / 总资产
  权益乘数 = 总资产 / 股东权益
```

**输出：**
- 三因素分解数值
- 主要 ROE 驱动因素识别
- 与行业/历史对比建议

## 3. 财务审计技能流水线

详见 [05-技能系统](./05-技能系统.md)。

完整审计链路：

```
输入：JSON 财务数据
  │
  ├─ 1. 验平衡（A = L + E）
  ├─ 2. 资产负债结构分析
  ├─ 3. 利润表分析
  ├─ 4. 现金流分析
  ├─ 5. 综合财务比率（四大类）
  ├─ 6. 杜邦 ROE 分解
  └─ 7. LLM 生成审计报告
       ├─ Executive Summary
       ├─ Health Score (0-100)
       ├─ Detailed Analysis
       ├─ Risk Flags
       └─ Recommendations
```

**设计意义：** 这模拟了真实审计中的「实质性分析程序」流程。

三个角色的会计学方法论：

|------|--------|

## 9. 答辩话术模板

> 在会计学领域，我们没有让 LLM 直接「算」财务数字，而是开发了 5 个确定性 Python 工具来处理三大报表分析、比率计算和杜邦分解。LLM 的角色是理解工具输出、组织论证、生成报告。对于标准化审计流程，我们用 Skill Pipeline 固化 SOP；对于需要多角度论证的场景，用三角色辩论团队模拟真实评审委员会。这种「工具算数 + LLM 解读 + 编排控制」的分层设计，既保证了数字准确性，又发挥了 LLM 的推理和表达能力。

## 10. 常见问题

**Q: 工具能处理真实的 Excel 财报吗？**  
A: 可通过 file_reader 读取 xlsx，但分析工具目前接受 JSON 输入。Excel → JSON 转换可作为扩展。

**Q: 比率_benchmark 从哪来？**  
A: 代码中硬编码了通用经验值（如 ROE 20% 为优秀）。实际应用可对接行业数据库。

**Q: 能否分析多期数据？**  
A: income_statement 支持 previous_period 字段做同比。更多期需扩展数据结构。

**Q: 审计报告 Health Score 怎么算的？**  
A: 由 LLM 基于工具输出综合判断（0-100），非公式计算。可改为加权评分模型。
