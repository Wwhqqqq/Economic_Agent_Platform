## 项目一句话

面向**会计学 / 财务分析**场景的全栈 LLM Agent 平台，集成 ReAct、Plan-Execute、多 Agent 辩论三种执行引擎，配套确定性财务工具、技能流水线、三层记忆与混合 RAG。

## 核心源码索引

```
backend/
├── main.py                          # 启动入口，注册 10 工具 + 3 技能
├── app/agent/

│   ├── runtime.py                   # ReAct 循环 + 上下文加载

│   └── plan_execute.py              # 规划-执行 Agent

│   └── debate_team.py               # 会计辩论团队
├── app/tools/                       # 工具系统
├── app/skills/                      # 技能系统
├── app/memory/                      # 三层记忆
├── app/rag/                         # 混合 RAG
└── app/api/chat.py                  # WebSocket 聊天

frontend/src/
├── views/ChatView.vue               # 主聊天界面
└── stores/chat.ts                   # WebSocket 事件处理
```
