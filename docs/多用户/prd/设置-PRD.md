# PRD — 设置中心

> **版本**：1.0  
> **日期**：2026-07-29  
> **状态**：待评审  
> **优先级**：P1（Phase 3，与会员体系、LLM 个人配置同期）  
> **路由**：`/settings`（含子路由，见 §3.2）  
> **关联页面**：`/membership`（会员中心）、`/login`（切换账号 / 退出后登录）

---

## 1. 背景与目标

### 1.1 背景

当前系统已具备：

- 侧栏「系统」分组下的 **「模型与接入」** 入口，路由 `/settings`，页面仅承载 LLM Provider 配置（`SettingsView.vue`）
- 侧栏底部 **用户卡片**：展示用户名、会员徽章、**退出** 按钮；底部 **版本号** `v1.0.0` 硬编码
- 认证体系：`auth` Store 含 `userId`、`username`、`userType`、`membershipExpiresAt`；后端 `users` 表含 `email`、`status` 等字段
- [11 — 页面与功能清单](../11-页面与功能清单/README.md) 要求设置页按 **普通用户 / 会员** 分支展示 LLM 能力，并将改密、操作记录等能力 **合并进设置页 Tab**

本 PRD 将零散的系统配置与用户相关操作 **收敛为统一的「设置中心」**，参考主流 SaaS / 协作 / AI 产品（Notion、Slack、ChatGPT、飞书、VS Code Settings）的信息架构，把现有 **「模型与接入」整页迁入设置子模块**，并补齐个人信息、外观、隐私与权限、版本信息、切换账号、退出登录等常见能力。

### 1.2 产品目标

| 目标 | 说明 |
|------|------|
| 统一入口 | 用户在一个页面完成账号、偏好、模型、隐私、关于等配置 |
| 结构清晰 | 左侧分类导航 + 右侧内容区，与系统 GlassCard 风格一致 |
| 能力归位 | 原「模型与接入」从侧栏独立项改为设置内「模型与接入」分组 |
| 身份感知 | 普通用户与会员在 LLM、部分隐私项上差异化展示 |
| 可扩展 | 为后续「操作记录」「数据导出」「多账号记忆」预留分组与路由 |
| 可验收 | 各分组有明确交互与接口约定，测试用例可覆盖 |

### 1.3 参考产品（信息架构）

| 产品 | 可借鉴点 |
|------|----------|
| **ChatGPT** | 左侧 Settings 分类：General / Personalization / Data controls / Account；退出与升级会员独立区块 |
| **Notion** | My account / My connections / Appearance / Notifications 分组；邮箱只读、头像占位 |
| **Slack** | Preferences 与 Account 分离；主题、语言在 Preferences；登出在 Account 底部 |
| **飞书** | 账号与安全、隐私、通用（外观/语言）、关于；切换账号返回登录页 |
| **VS Code** | 左侧树形分类 + 右侧详情；搜索设置（本阶段可选 P2） |

本 PRD 采用 **「左侧分类导航 + 右侧详情」** 布局，与上述产品一致，降低学习成本。

### 1.4 不在本次范围

- 第三方 OAuth 绑定（微信、GitHub、企业 SSO）
- 多设备登录管理与远程踢下线（仅预留入口说明）
- 完整通知中心（邮件/浏览器 Push 规则配置）
- 账号注销（Delete account）的自动审批流程（仅预留说明文案）
- 设置项全文搜索（P2 可选）
- 移动端独立设置 App / 响应式专项适配（遵循现有 Web 自适应即可）

## 2. 用户与场景

### 2.1 目标用户

已登录的会计通用工作台用户（普通用户 / 会员用户）。

### 2.2 核心场景

| 编号 | 场景 | 期望结果 |
|------|------|----------|
| S1 | 用户想查看自己的账号信息 | 在「账号与资料」看到用户名、邮箱、会员状态 |
| S2 | 用户想修改 LLM API Key | 进入「模型与接入」，按会员权限编辑并保存 |
| S3 | 用户想切换深色模式 | 在「外观与显示」切换主题，立即生效并持久化 |
| S4 | 用户想修改登录密码 | 在「隐私与安全」完成旧密码 + 新密码修改 |
| S5 | 用户想换另一个账号登录 | 点击「切换账号」，清除当前会话并跳转登录页 |
| S6 | 用户想退出 | 在设置页或侧栏点击「退出登录」，回到登录页 |
| S7 | 用户想查看版本与协议 | 在「关于」看到应用版本、构建信息、链接 |
| S8 | 普通用户打开 LLM 配置 | 只读展示平台默认模型，引导升级会员以自定义 |
| S9 | 用户从侧栏点击「设置」 | 进入设置中心默认页（账号与资料），而非直接进入模型配置 |

## 3. 页面与布局

### 3.1 侧栏导航变更（全局）

| 变更前 | 变更后 |
|--------|--------|
| 系统分组 → **「模型与接入」** → `/settings` | 系统分组 → **「设置」** → `/settings` |
| 用户卡片内「退出」保留 | 保留；与设置内「退出登录」行为一致 |
| 底部 `v1.0.0` 硬编码 | 改为从「关于」模块的版本接口或构建常量读取（见 §5.6） |

| 路由 | 分组 | Phase |

| `/settings/activity` | 我的操作记录 | P3 |

**布局规范**：

- 外层：`page-shell` + `PageHeader`（与现有页面一致）
- 左侧导航宽度：约 `220px`，当前项高亮（`active`：主色左边框 + 浅紫背景）
- 右侧内容：最大宽度约 `720px`，表单纵向排列
- 窄屏（`<768px`）：左侧导航改为顶部横向 Tab 或折叠菜单（P2 细化）

### 3.4 视觉规范

与系统全局及 [注册功能 PRD](./注册功能-PRD.md) 保持一致：

- 容器：`GlassCard`
- 主按钮：`ui-btn-primary`；危险操作（退出）：红色描边或红色文字按钮
- 只读字段：灰色背景或纯文本 + 「复制」图标
- 会员受限区域：`LockedFeature` 或 `UpgradePrompt` 蒙层（与 ChatView 一致）
- 设置左侧导航图标建议：User、Brush、Connection、Lock、InfoFilled

## 4. 分组功能详述

### 4.1 账号与资料（`/settings/account`）

#### 4.1.1 个人信息卡片

| 字段 | 来源 | 可编辑 | 说明 |
|------|------|--------|------|
| 头像 | 占位 | P2 | 首版用用户名首字母圆形头像，与侧栏一致 |
| 用户名 | `GET /api/auth/me` | 否（P2 可改） | 展示 `username` |
| 邮箱 | `GET /api/auth/me` | 否（P2 可改） | 注册邮箱；未绑定时展示「未绑定」 |
| 用户 ID | `user_id` | 否 | 小号灰色文字，便于工单反馈 |
| 账号类型 | `user_type` + 会员到期 | 否 | `MembershipBadge` + 到期时间 |
| 注册时间 | `created_at` | 否 | 格式化 `YYYY-MM-DD HH:mm` |

**操作按钮**：

| 按钮 | 行为 |
|------|------|
| **管理会员** | 跳转 `/membership`（会员展示续费/权益；普通用户展示升级） |
| **切换账号** | 见 §4.1.3 |
| **退出登录** | 见 §4.1.4；本页底部与左侧导航底部均提供入口 |

#### 4.1.2 会员摘要（嵌入账号卡片下方）

| 用户类型 | 展示 |
|----------|------|
| 普通用户 | 简要权益对比 + 「升级会员」按钮 → `/membership` |
| 会员 | 到期时间、剩余天数（可选）、「会员中心」链接 |

数据来自 `GET /api/membership/status`（与 [11 — 页面与功能清单](../11-页面与功能清单/README.md) 一致）。

#### 4.1.3 切换账号

参考 ChatGPT / 飞书「切换账号」：

1. 弹出确认对话框：「切换账号将退出当前登录，是否继续？」
2. 确认后：调用登出逻辑（见 §4.1.4），**不清除**本地非敏感偏好（如主题，见 §4.2）
3. 跳转 `/login?switch=1`（可选 query 供登录页展示「请登录其他账号」提示）

本阶段 **不** 实现多账号列表缓存；每次切换均需重新输入凭据。

#### 4.1.4 退出登录

| 项 | 说明 |
|----|------|
| 触发位置 | ① 设置左侧导航底部 ② 账号与资料页底部 ③ 侧栏用户卡片（保留现状） |
| 交互 | 可选二次确认（「确定退出？」）；会员/普通用户一致 |
| 前端 | 清除 `auth_token`、auth Store 状态；断开 WebSocket |
| 后端 | P1 调用 `POST /api/auth/logout`（jti 黑名单，Phase 4）；未实现时仅前端清 Token |
| 跳转 | `/login` |

### 4.2 外观与显示（`/settings/appearance`）

参考 Notion / Slack / VS Code 主题设置。

| 设置项 | 控件 | 默认值 | 持久化 |
|--------|------|--------|--------|
| **主题模式** | 三选一卡片：浅色 / 深色 / 跟随系统 | 浅色 | `localStorage.theme` |
| **界面密度** | 紧凑 / 标准 | 标准 | `localStorage.density`（P2，首版可仅主题） |
| **语言** | 下拉：简体中文 / English | 简体中文 | P2；首版隐藏或 disabled「即将推出」 |

**主题行为**：

- 切换后立即应用 CSS 变量（扩展 `theme.css` 深色 token）
- 「跟随系统」监听 `prefers-color-scheme`
- 切换账号时 **保留** 主题偏好（仅存 localStorage，与 user_id 无关）

**验收**：刷新页面后主题保持不变。

### 4.3 模型与接入（`/settings/model`）

> **本分组承接现有 `SettingsView.vue` 全部能力**，自侧栏独立入口迁入此处；交互与字段 **以当前实现为基线**，按用户类型补充权限差异。

#### 4.3.1 迁入范围（现状对齐）

以下内容与当前「模型与接入」页一致，整体移入 `/settings/model`：

| 模块 | 现状能力 |
|------|----------|
| 运行状态 | 向量知识库 / 知识图谱 / 模型服务 状态 Tag |
| 默认模型接入 | 下拉选择 default provider |
| Provider 卡片 | DeepSeek、OpenAI 兼容、Anthropic、Custom 网关 |
| 每 Provider 配置 | API Key、网关地址（非 Anthropic）、模型名称、采样温度 |
| 保存 | 单 Provider 保存按钮；更新默认 Provider |

#### 4.3.2 权限与展示差异

| 用户类型 | 模型与接入 |
|----------|------------|
| **普通用户** | 只读：展示平台默认 Provider 与模型名；API Key 显示「******」不可编辑；保存按钮隐藏；顶部提示「升级会员后可配置个人模型接入」+ 跳转会员中心 |
| **会员** | 完整读写：可配置个人 LLM（`user_llm_settings` 表，见 [11 — 功能总表](../11-页面与功能清单/README.md) S-01~S-04） |
| **管理员**（若存在） | 与现网一致，可写全局 `settings.json` / 平台级配置 |

#### 4.3.3 后端接口（目标态）

| 方法 | 路径 | 普通用户 | 会员 |
|------|------|----------|------|
| GET | `/api/settings/llm` | 返回平台默认 + 脱敏 | 返回个人配置 + 平台 fallback |
| PUT | `/api/settings/llm` | 403 | 写入个人配置 |
| PUT | `/api/settings/llm/default` | 403 | 可改个人默认 Provider |

> **现状说明**：当前 `PUT /api/settings/llm` 使用 `require_admin`；实施本 PRD 时需改为按 `user_type` 分支，与普通用户只读策略对齐。

#### 4.3.4 UI 调整要点

- 面包屑：`系统 / 设置 / 模型与接入`
- PageHeader 标题：**模型与接入**（子标题保留现文案）
- 从设置左侧导航进入时，**不再**使用独立顶栏标题「模型与接入」作为侧栏项

### 4.4 隐私与安全（`/settings/privacy`）

参考 ChatGPT Data controls + 常见账号安全页。

#### 4.4.1 修改密码

| 字段 | 规则 |
|------|------|
| 当前密码 | 必填 |
| 新密码 | 至少 6 位，仅字母、数字、下划线（与注册一致） |
| 确认新密码 | 与新密码一致 |

| 项 | 说明 |
|----|------|
| 接口 | `POST /api/auth/change-password`（Phase 4，见 A-05） |
| 成功 | Toast「密码已更新」；可选要求重新登录 |
| 失败 | 当前密码错误 → 字段级错误提示 |

#### 4.4.2 登录与会话

| 内容 | 首版 |
|------|------|
| 最近登录时间 | 只读，来自 `last_login_at` |
| 当前会话 | 文案：「您正在当前设备上使用」 |
| 其他设备管理 | 灰色 disabled +「即将推出」 |

#### 4.4.3 数据与权限

| 设置项 | 首版行为 |
|--------|----------|
| **对话数据** | 说明：会话存储于服务端，仅本人可见；链接「了解数据隔离」→ 文档 |
| **知识库文档** | 说明：上传文件归属当前账号；会员可见专享库只读规则 |
| **模型 API Key** | 说明：Key 加密存储，应用内不可被其他用户读取（会员个人配置） |
| **导出我的数据** | 按钮 disabled + P3 占位 |
| **注销账号** | 文字链接 → 说明页或邮件联系管理员（不自动删除） |

#### 4.4.4 权限说明（只读）

以列表形式说明当前账号权限，便于用户理解：

| 能力 | 普通用户 | 会员 |
|------|----------|------|
| ReAct 对话 | ✓ | ✓ |
| Plan-Execute / Multi-Agent | ✗ | ✓ |
| 会员专享技能 | ✗ | ✓ |
| 个人 LLM 配置 | ✗ | ✓ |
| 会员专享知识库 | ✗ | 只读 |

数据可来自 `GET /api/membership/status` 的 `benefits` 字段。

### 4.5 关于（`/settings/about`）

参考应用「About」对话框。

| 内容 | 说明 |
|------|------|
| 应用名称 | 会计通用工作台（与 `platformStore.platformName` 一致） |
| 版本号 | 如 `v1.0.0`；来自 `package.json` 或构建注入的 `__APP_VERSION__` |
| 构建信息 | 可选：Git commit 短 hash、构建日期（生产环境） |
| 后端状态 | 链接跳转或折叠展示 `/health` 摘要（与模型页状态不重复罗列） |
| 开源许可 | 链接到仓库 LICENSE（若存在） |
| 用户协议 / 隐私政策 | 外链或 `docs` 占位页；首版可为 `#` + 「敬请期待」 |
| 检查更新 | 按钮：对比远程版本（P2）；首版点击 Toast「当前已是最新版本」 |

**侧栏底部版本号**：改为与关于页同一数据源，避免多处硬编码不一致。

## 5. 接口设计

### 5.1 已有接口（复用）

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/auth/me` | 账号与资料展示 |
| GET | `/api/membership/status` | 会员摘要、权限列表 |
| GET | `/api/settings/llm` | 模型与接入 |
| PUT | `/api/settings/llm` | 保存 Provider（需改造权限） |
| PUT | `/api/settings/llm/default` | 默认 Provider（需改造权限） |
| GET | `/api/system/status` | 运行状态 Tag |

### 5.2 新增接口（建议）

| 方法 | 路径 | 说明 | Phase |
|------|------|------|-------|
| POST | `/api/auth/logout` | 登出，jti 入黑名单 | P1/P4 |
| POST | `/api/auth/change-password` | 修改密码 | P2/P4 |
| GET | `/api/settings/preferences` | 读取服务端偏好（若需跨设备同步） | P2 |
| PUT | `/api/settings/preferences` | 保存服务端偏好 | P2 |
| GET | `/api/app/version` | 版本号、构建信息 | P1 |
| GET | `/api/account/activity` | 我的操作记录 | P3 |

### 5.3 GET /api/auth/me 响应扩展（建议）

在现有字段基础上，设置页需要：

```json
{
  "user_id": 1,
  "username": "demo_regular",
  "email": "user@example.com",
  "user_type": "regular",
  "membership_expires_at": null,
  "status": "active",
  "created_at": "2026-07-28T10:00:00Z",
  "last_login_at": "2026-07-29T09:00:00Z"
}
```

### 5.4 GET /api/app/version（建议）

```json
{
  "app_name": "会计通用工作台",
  "version": "1.0.0",
  "build": "f1ace8d",
  "build_date": "2026-07-29T00:00:00Z"
}
```

### 5.5 错误码（设置相关）

| code | 场景 | 前端处理 |
|------|------|----------|
| `MEMBERSHIP_REQUIRED` | 普通用户 PUT LLM | 升级引导 |
| `INVALID_CURRENT_PASSWORD` | 改密时旧密码错误 | 当前密码字段标红 |
| `PASSWORD_MISMATCH` | 确认密码不一致 | 确认密码字段标红 |
| `UNAUTHORIZED` | 未登录 | 跳转登录 |

## 6. 交互与状态

### 6.1 设置页访问控制

| 状态 | 行为 |
|------|------|
| 未登录 | 路由守卫跳转 `/login?redirect=/settings/account` |
| 已登录 | 正常访问各子路由 |
| Token 过期 | API 401 → 清 Token → 跳转登录 |

### 6.2 表单通用规范

| 时机 | 行为 |
|------|------|
| 修改可编辑项 | 展示「保存」按钮；或失焦自动保存（外观主题除外，主题即时生效） |
| 保存中 | 按钮 loading + disabled |
| 保存成功 | ElMessage.success |
| 保存失败 | ElMessage.error + 字段错误（若有） |

### 6.3 危险操作

| 操作 | 确认 |
|------|------|
| 退出登录 | 可选单按钮；建议轻量 confirm |
| 切换账号 | 必须 confirm |
| 修改密码成功 | 可选 confirm「需重新登录」 |
