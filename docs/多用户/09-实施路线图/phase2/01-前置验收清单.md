## 5. 快速冒烟脚本（建议保存为团队共享）

```bash
# 1. 健康检查
curl -s http://localhost:8000/health | python -m json.tool

# 2. 用户 A 登录
curl -s -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test_regular","password":"Test123456"}'

# 3. 用户 B 登录（对比隔离）
curl -s -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test_member","password":"Test123456"}'

# 4. 确认 knowledge 当前为全局（Phase 2 前的基线）
# 用 A 的 token 上传文档后，用 B 的 token 调 GET /api/knowledge/documents
# 预期：Phase 2 前 B 能看到 A 的文档 → Phase 2 后应看不到
```
