## Phase 2 一句话目标

> **所有私有数据带 `user_id` 全链路隔离**；RAG 仅检索当前用户的 `visibility=private` 文档；取消 skill 全局污染；为 Phase 3 的 `visibility=member` 检索分支预留 `user_type` 参数。
