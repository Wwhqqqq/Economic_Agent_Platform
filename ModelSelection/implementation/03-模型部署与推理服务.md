# 03 — 模型部署与推理服务

## 1. 本步目标

在 **GN7 T4 16G** 上部署：

## 2. vLLM 部署 Qwen 7B

### 2.1 安装

```bash
source ~/venv/infer/bin/activate  # 或新建 venv
pip install vllm openai
```

### 2.2 方案 A：基座 AWQ + LoRA（推荐，省显存）

先对基座做 AWQ 量化（若尚未量化，可用预量化权重 `Qwen/Qwen2.5-7B-Instruct-AWQ`）：

```bash
huggingface-cli download Qwen/Qwen2.5-7B-Instruct-AWQ \
  --local-dir /opt/models/Qwen2.5-7B-Instruct-AWQ
```

启动 vLLM（**带 LoRA**）：

```bash
export CUDA_VISIBLE_DEVICES=0

python -m vllm.entrypoints.openai.api_server \
  --model /opt/models/Qwen2.5-7B-Instruct-AWQ \
  --served-model-name qwen7b-accounting \
  --host 0.0.0.0 \
  --port 8000 \
  --dtype auto \
  --max-model-len 8192 \
  --gpu-memory-utilization 0.85 \
  --enable-lora \
  --lora-modules accounting=/opt/models/qwen7b-accounting-lora \
  --max-lora-rank 32
```

### 2.3 方案 B：合并后全精度/FP16 模型

```bash
python -m vllm.entrypoints.openai.api_server \
  --model /opt/models/Qwen2.5-7B-Instruct-Accounting-Merged \
  --served-model-name qwen7b-accounting \
  --host 0.0.0.0 \
  --port 8000 \
  --max-model-len 8192 \
  --gpu-memory-utilization 0.90
```

### 2.4 验证 vLLM

```bash
curl http://127.0.0.1:8000/v1/models

curl http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen7b-accounting",
    "messages": [{"role":"user","content":"简要说明流动比率含义"}],
    "max_tokens": 256
  }'
```

若使用 LoRA，请求中指定：

```json
"model": "accounting"
```

（与 `--lora-modules` 名称一致，具体以 vLLM 版本文档为准。）

### 2.5 systemd 守护（可选）

```ini
# /etc/systemd/system/vllm-qwen7b.service
[Unit]
Description=vLLM Qwen7B Accounting
After=network.target

[Service]
Type=simple
User=root
Environment=CUDA_VISIBLE_DEVICES=0
ExecStart=/opt/venv/infer/bin/python -m vllm.entrypoints.openai.api_server \
  --model /opt/models/Qwen2.5-7B-Instruct-AWQ \
  --served-model-name qwen7b-accounting \
  --host 0.0.0.0 --port 8000 \
  --enable-lora --lora-modules accounting=/opt/models/qwen7b-accounting-lora
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now vllm-qwen7b
```

## 3. PaddleOCR-VL 1.6 部署

### 3.1 独立 Python 服务（推荐起步）

创建 ` /opt/services/paddleocr_vl/server.py`（FastAPI 包装 CLI/API）：

```python
# 示意：按 PaddleOCR 1.6 官方 API 调整
from fastapi import FastAPI, UploadFile, File

app = FastAPI()

@app.post("/v1/doc/parse")
async def parse_doc(file: UploadFile = File(...)):
    raw = await file.read()
    # 调用 PaddleOCR-VL 1.6 pipeline，返回 markdown / json
    # result = pipeline.predict(raw)
    return {"status": "ready", "markdown": "...", "engine": "paddleocr-vl-1.6"}

@app.get("/health")
def health():
    return {"ok": True}
```

```bash
pip install fastapi uvicorn paddlepaddle-gpu paddleocr
uvicorn server:app --host 0.0.0.0 --port 8080
```

> **重要**：以 [PaddleOCR 官方 1.6 文档](https://www.paddleocr.ai/latest/en/version3.x/algorithm/PaddleOCR-VL/PaddleOCR-VL-1.6.html) 中的 **Doc Parser / VL 推理接口** 为准实现 `parse` 逻辑。

### 3.2 Docker（可选）

若官方提供镜像，优先使用；否则自建 Dockerfile 基于 `paddlepaddle/paddle` GPU 镜像，挂载 `/opt/models/paddleocr-vl`。

### 3.3 验证 OCR 服务

```bash
curl -X POST http://127.0.0.1:8080/v1/doc/parse \
  -F "file=@sample_report.pdf"
```

应返回可读的 Markdown 或结构化 JSON（含表格区域）。

## 4. 同机显存分配（T4 16G）

| 服务 | 显存约 | 说明 |
|------|--------|------|
| vLLM Qwen 7B AWQ | 6～8 GB | `--gpu-memory-utilization 0.85` |
| PaddleOCR-VL 1.6 | 2～4 GB | 可在同卡，或 OCR 用 CPU（慢） |

**同卡启动顺序**：先起 vLLM，再起 OCR；若 OOM，将 OCR 设为 **CPU 模式** 或 **分时批处理**（仅入库任务时启动 OCR 进程）。

## 5. 网络安全

| 端口 | 暴露策略 |
|------|----------|
| 8000 vLLM | **仅 VPC 内网**；禁止公网 0.0.0.0/0 |
| 8080 OCR | 仅内网；平台 backend 访问 |
| 8082 平台 | 公网 + HTTPS（gateway） |

阿里云安全组：允许 `10.0.0.0/8` 内网互访；SSH 限制办公 IP。
