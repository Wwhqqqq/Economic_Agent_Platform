# 01 — 环境准备与模型下载

## 1. 本步目标

- 微调机（Windows + 5080）与推理机（GN7 T4）环境就绪  
- 下载 **Qwen2.5-7B-Instruct** 与 **PaddleOCR-VL 1.6** 权重

## 2. 微调环境（本地 Windows + 5080）

### 2.1 推荐：WSL2 Ubuntu 22.04

PowerShell（管理员）：

```powershell
wsl --install -d Ubuntu-22.04
wsl --update
```

WSL 内安装 NVIDIA 容器/驱动支持（Windows 侧已装最新 Game Ready / Studio 驱动即可，WSL 内验证）：

```bash
nvidia-smi
```

应能看到 **RTX 5080 16GB**。

### 2.2 Python 与 CUDA 工具链

```bash
sudo apt update && sudo apt install -y git git-lfs python3.10-venv python3-pip
python3 -m venv ~/venv/agent-train
source ~/venv/agent-train/bin/activate
pip install -U pip wheel
```

安装 PyTorch（按 [pytorch.org](https://pytorch.org) 选 CUDA 12.x 对应命令），例如：

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

验证：

```bash
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

### 2.3 下载 Qwen2.5-7B-Instruct

**方式 A：Hugging Face（国际网络）**

```bash
pip install huggingface_hub
export HF_ENDPOINT=https://hf-mirror.com   # 国内可选镜像

huggingface-cli download Qwen/Qwen2.5-7B-Instruct \
  --local-dir /mnt/e/models/Qwen2.5-7B-Instruct \
  --local-dir-use-symlinks False
```

**方式 B：ModelScope（国内推荐）**

```bash
pip install modelscope
modelscope download --model Qwen/Qwen2.5-7B-Instruct \
  --local_dir /mnt/e/models/Qwen2.5-7B-Instruct
```

> 若选用 **Qwen3-8B**，将模型 ID 换为 `Qwen/Qwen3-8B` 等，后续步骤相同。

**校验**：目录内应含 `config.json`、`model.safetensors` 或分片、`tokenizer.json`。

### 2.4 下载 PaddleOCR-VL 1.6

参考官方文档：[PaddleOCR-VL 1.6 Introduction](https://www.paddleocr.ai/latest/en/version3.x/algorithm/PaddleOCR-VL/PaddleOCR-VL-1.6.html)

```bash
# PaddlePaddle GPU（CUDA 11.8 示例，以官网为准）
pip install paddlepaddle-gpu
pip install "paddleocr[doc-parser]"

mkdir -p /mnt/e/models/paddleocr-vl
```

按官方指引下载 **PaddleOCR-VL-1.6** 推理权重到 `/mnt/e/models/paddleocr-vl/`。

**Smoke test（单张图片）**：

```bash
paddleocr doc_parser -i ./test_invoice.png --vl_rec_model_dir /mnt/e/models/paddleocr-vl
```

能输出 Markdown / 结构化文本即成功。

## 3. 推理环境（阿里云 GN7 T4）

### 3.1 系统

- 镜像：**Ubuntu 22.04 64位 GPU 镜像**（预装驱动更佳）  
- 规格：**GN7.2XLARGE32**（8vCPU / 32GiB / 1×T4 16GB）  
- 系统盘：**≥100GB**（模型 + Docker 镜像）  

### 3.2 基础软件

```bash
sudo apt update && sudo apt install -y git git-lfs docker.io docker-compose-plugin
sudo usermod -aG docker $USER
# 重新登录后
docker --version
nvidia-smi
```

安装 **NVIDIA Container Toolkit**（Docker 内使用 GPU）：

```bash
# 见 NVIDIA 官方文档：nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
docker run --rm --gpus all nvidia/cuda:12.4.0-base-ubuntu22.04 nvidia-smi
```

### 3.3 同步模型到 GPU 机

任选其一：

| 方式 | 命令示例 |
|------|----------|
| `scp` / `rsync` | 从本机传到 `/opt/models/` |
| 对象存储 | 上传 OSS/COS 后在 GPU 机 `ossutil`/`coscmd` 下载 |
| 直接在 GPU 机下载 | 重复 2.3、2.4 的 download 命令 |
