## 8. 常见问题

| 现象 | 排查 |
|------|------|
| 聊天超时 120s | vLLM 是否可达；`max-model-len` 过大；调 `AGENT_TIMEOUT_SECONDS` |
| 回答不像微调 | 前端 model 名是否与 vLLM 一致；LoRA 是否加载 |
| RAG 无引用 | 文档 job 是否 ready；Chroma 是否有 doc |
| PDF 入库空 | PaddleOCR-VL URL；`PADDLE_OCR_VL_ENABLED` |
| GPU OOM | 降低 `gpu-memory-utilization`；7B 换 AWQ；OCR 改 CPU |
